## 1. QA evidence and independent acceptance states
Acceptable evidence classes: `OBSERVED_REAL_PIXELS`, `MEASURED_FILE_BYTES`, `VERIFIED_SOURCE_TEXT`, `USER_VISUAL_FEEDBACK`, `DOCUMENT_SPECIFICATION`, `SYNTHETIC_TEST_ONLY`, `NOT_RUN`, `NOT_CHECKED`, `UNVERIFIED`, `BLOCKED`. Do not pretend a documented intention equals a rendered result.

Separate these states in the run manifest:
- `commission_status`: `AUTHORIZED | NOT_AUTHORIZED`;
- `source_status`: `LOCKED_REVISION | STALE | UNVERIFIED`;
- `storyboard_status`: `LOCKED | NEEDS_REVIEW | NOT_CREATED`;
- `asset_status`: `NOT_STARTED | RENDERED_DRAFT | LETTERED | REPAIRED | FILE_MISSING`;
- `page_geometry_status`: `NOT_MEASURED | PASS_EXACT_RATIO | FAIL_EXACT_RATIO | BLOCKED_NO_BYTES | DRAFT_EXCEPTION_NOT_RELEASE`;
- `internal_working_qa_status`: `NOT_CHECKED | PASS | FAIL | BLOCKED`;
- `owner_editorial_status`: `NOT_REVIEWED | PROVISIONAL_ACCEPTED | ACCEPTED | REJECTED`;
- `rights_status`: `UNVERIFIED | AUTHORIZED | RESTRICTED`;
- `native_detail_status`: `NOT_CHECKED | ACCEPTABLE | BELOW_TARGET | BLOCKED`;
- `persistence_status`: `LOCAL_FILE_VERIFIED | COMMIT_VERIFIED | NOT_VERIFIED`;
- `release_status`: `NOT_AUTHORIZED | RELEASE_APPROVED | PUBLISHED_VERIFIED`.

**Critical distinction:** In `AUTO_COMPLETE`, `INTERNAL_WORKING_QA_PASS` permits rendering the *next already authorized batch*. It is **not** a substitute for owner approval, rights clearance, native detail or public release. In explicit stepped modes, pause at the requested boundary even after an internal pass.

## 2. Commission preflight and budget inventory

Before rendering, verify (a) one exact eligible Public Chronicle Output A and its date, full daily title and actual source version, (b) exact public Challenge A, (c) rights/canon/time/visual packet, (d) N=8 unless the user explicitly specified another integer 4–20, (e) generation mode provenance and any explicit pause policy, (f) a frozen P01…PN set of unique story-bearing page briefs, and (g) a P01 integrated intro brief tied to the first actual source scene.

Page allocation must be computed as:

```python
assert isinstance(N, int) and not isinstance(N, bool) and 4 <= N <= 20
full_sheets, remainder_pages = divmod(N, 4)
planned_full_sheets = [
    [f"P{i:02d}" for i in range(4*s + 1, 4*s + 5)]
    for s in range(full_sheets)
]
planned_remainder = [f"P{i:02d}" for i in range(4*full_sheets + 1, N + 1)]
assert sum(map(len, planned_full_sheets)) + len(planned_remainder) == N
```

No false pad or filler page to achieve a perfect sheet. `P01` always counts in N. Allowed examples:

| N | Full sheets | True leftover pages | Only challenge page | P01 identity |
|---:|---|---|---|---|
| 4 | S01 P01–P04 | none | P04 | Hybrid intro + real opening beat |
| **8 default** | S01 P01–P04; S02 P05–P08 | none | P08 | Hybrid intro + real opening beat |
| 7 | S01 P01–P04 | P05/P06/P07 separately | P07 | Hybrid intro + real opening beat |
| 12 | S01–S03 (4 each) | none | P12 | Hybrid intro + real opening beat |
| 16 explicit legacy commission | S01–S04 (4 each) | none | P16 | Hybrid intro only when generating/revising under v0.09.07 |
| 20 | S01–S05 (4 each) | none | P20 | Hybrid intro + real opening beat |

N<4 or N>20 is a **commission-policy failure**, not a license to silently clamp or replace the user’s number. Preserve old N16 jobs at N16 if explicitly commissioned, never reset the count on `COMIC_CONTINUE`.

## 3. P01 cover-plus-scene QA (NEW)

Check the **final, extracted P01 raster**, not merely the planned prompt. Human art and typography validation must confirm:

| QA ID | Measurable or inspectable requirement | Failure condition |
|---|---|---|
| `SC_P01_HEADER_INTEGRATED` | Daily-intro title/identity is part of the P01 illustrated page, no P00/extra cover | Title-only P00, separate promotional art counted in N, cover-only P01 |
| `SC_P01_HEADER_REGION` | Intro header spans **approximately** top quarter to third, documented design fraction | Header absent, dominates nearly entire page, tiny unreadable strip |
| `SC_P01_FIRST_BEAT` | At least one clear action/event from chronicle’s first real scene advances on P01 | First act postponed to P02, title-only montage, invented prologue |
| `SC_DAILY_TITLE_DATE_EXACT` | Full daily title/date match selected Public Output A; subordinate episode/day metadata correct | Prior-day title, only episode title used, invented date, spelling error |
| `SC_HEADER_SCENE_OBJECT` | Any header motif/assets derive from genuine first scene or authorized neutral Classies brand | Later secret revelation shown as already known; unverified report made physical fact |
| `SC_P01_SAFE_LETTERING` | Masthead contrasts with background, legible at actual phone crop; dialogue not crushed | Text clips, appears over busy faces/signs, unreadable type |
| `SC_P01_COMPLETE_ASPECT` | Full P01 including top header measures exact `16w=9h` | Cropping header changes ratio; 2:3 cells used or fake padding |
| `SC_NO_REPEATED_INTRO` | P02…PN do not restart the chronicle’s full identity/cover | Full masthead or recap repeated on later sheets |
| `SC_CHALLENGE_NOT_IN_P01` | No Challenge A on P01 because 4≤N | Challenge, quiz or restricted hint appears in intro |

The 25%–33% fraction is a **visual design range**, not a mathematical pixel crop validation that justifies destructive recomposition. When the text is long or image complexity high, adjust the creative layout, not the 9:16 canvas or first-beat requirement. Record estimated fraction plus reviewer evidence, and distinguish `DOCUMENT_SPECIFICATION` from `OBSERVED_REAL_PIXELS`.

## 4. AUTO_COMPLETE batch-validation state machine (NEW)

`VALIDATE_SOURCE → LOCK_N_STORYBOARD → LOCK_P01_HEADER → VALIDATE_PROVIDER_SIZE_CAPABILITY → RENDER_BATCH → MEASURE_ORIGINAL → EXTRACT_PAGES → AUDIT_STORY_CHARACTERS_TEXT_RIGHTS → ACCEPT_FOR_INTERNAL_CONTINUITY / REPAIR_SAME_IDS / BLOCK → SAVE_CURSOR → NEXT_BATCH (only if internal PASS and mode AUTO_COMPLETE) → FINAL PN → GLOBAL_QA → HANDOVER`.

**Do not pause for a new user prompt after a successfully validated image batch in default `AUTO_COMPLETE`.** Validated means only `INTERNAL_WORKING_QA_PASS` for the relevant integrity and content checks. This internal stage does not preempt user/editor’s postproduction review. For `SHEET_STEP`/`PAGE_STEP`, wait at the expressly requested point. A user-supplied “pause after first sheet” supersedes auto.

### 4.1 Pre-batch checks
- Confirm actual next P IDs from immutable `next_page_cursor`; N and mode from original commission, not recalculated by the default each time.
- Confirm visual reference art and the last valid outgoing-state capsule; compare faces, clothes, props, knowledge, true places, P/H/F and time-of-day.
- For S01, include P01 header and first-scene beat; for S02 onward, **suppress** full masthead and story introduction.
- No unsupported real-world conclusions, archive access, evacuation advice, transmitted/acknowledged letter, invented probe movement or illicit branding.
- Set `challenge_allowed=false` for every P before PN; do **not send exact Challenge A text** to a nonfinal image render.
- Check provider’s **actual** 9:16 internal page capability; when not verified, prefer real single-page generation and lossless 2×2 assembly.

### 4.2 Post-batch checks / decision
- Inspect actual source and extracted page byte dimensions; each page must satisfy **`16*w == 9*h`** exactly. A prompt claiming 9:16 is not evidence.
- Confirm correct count, order, all complete page boundaries, no filler/duplicates, no early challenge, no repeated cover/recap, correct source-grounded distinct scene actions.
- Compare actual actor likeness and scene/prop state; check exact visible names, labels, receipts, dates and scriptural references and literal final raster text.
- Preserve original/provider size, crop rectangles, per-page source/art SHA-256 and actual native-vs-export transformation history. Never silently turn an upscale into a genuine 1080×1920 image.
- If all mandatory **internal** checks pass, record `INTERNAL_WORKING_QA_PASS`, next cursor and continue within the same turn in `AUTO_COMPLETE`. This is not public release approval.
- If aspect/content failures are repairable, revise only affected existing IDs and re-check. If not solvable, **STOP** with `BLOCKED` and precise page/batch cursor, even in `AUTO_COMPLETE`. Never continue rendering downstream from failed aspect geometry.
- If the provider/tool cannot handle more image calls in this interaction, record exact completed and missing IDs, no fake future completion promise or background execution.

### 4.3 Post-final PN checks
- Exactly commissioned N unique pages exist, actual file references verified, one P01 hybrid cover plus opening scene, and exactly one complete public Challenge A **at the literal bottom of PN**, nowhere else.
- File- and human-based C01–C22 results filled with actual evidence/missing-state statuses; proofs are per revision, not inherited from an unrelated prior episode.
- Deliver one consolidated report after completion or a real irreducible blocking failure. Do not generate CC-04 media without a separate request.

## 5. Geometry enforcement retained from v0.09.06

An output **exact ratio test** for integer width/height is `16*w == 9*h`. At true native page 1080×1920, four-page sheet is 2160×3840. The historically observed 1024×1536 2×2 sheet yields 512×768 per quadrant: 2:3, `C11_PAGE_ASPECT=FAIL`. A 1080×1920 **sheet** produces 540×960 quadrants: exact ratio passes but native detail is below the preferred target. A resized/exported 1080×1920 cropped/stretched from 512×768 must not be called originally native 1080×1920. Native source capability is either `VERIFIED`, `NOT_VERIFIED` or `UNSUPPORTED` with evidence.

Measure geometry at stages: `REQUESTED_SIZE`, `PROVIDER_REPORTED_SIZE`, `MEASURED_ORIGINAL_SIZE`, `EXTRACTED_PAGE_SIZE`, `POST_LETTERING_PAGE_SIZE`, `EXPORT_SIZE`; each with origin/transform history. For exact zero-gutter sheets, each page crop is a true quadrant; otherwise specify exact nonoverlapping rectangles and verify every extracted page independently. Sheet aspect alone is insufficient. Do not use approximation such as `<2% difference` for release masters. Crop/stretch/padding that removes source-critical content or fabricates native compliance is disallowed; nonconforming art can be **draft reference only**.

A mechanical checker may validate pixel shape, file digests, page counts, duplicate byte hashes and lossless assembly. It **cannot** verify text semantics, source fidelity, character consistency, consent, rights or publication readiness. The previous `cc03_geometry_guard_v0.09.06.py` utility remains compatible for exact geometry measurements and can be retained in the project’s production tooling when it is available.

## 8. Naming and output inventory

Suggested file scheme for a run `<DAY_ID>`:

- A complete four-page sheet: `<DAY_ID>_S01_P01-P04_r01.png`, then `_S02_P05-P08_r01.png` for ordinary N8; successive four-page sheets continue with N as commissioned.
- Each genuine complete page: `<DAY_ID>_P01_r01.png`, …, `<DAY_ID>_P08_r01.png` (default). P01 file contains title header **and story**. Remainders always exist as individual P files.
- Same-ID repairs increment `r02`, `r03`; they do **not** become new P IDs.
- Final consolidated reports/manifest should name actual assessed run revision and mark `PROVISIONAL` where rights/editorial/geometry are pending.

The first sheet's full composite need not visually be 9:16 if deliberate outer gutters or irregular cells are used, but **each extracted page is independently measured 9:16** with recorded crop boxes. A zero-gutter 2×2 of equal 9:16 pages is itself 9:16. Do not extract quadrants from a 2:3 sheet and pretend their ratio changed.
