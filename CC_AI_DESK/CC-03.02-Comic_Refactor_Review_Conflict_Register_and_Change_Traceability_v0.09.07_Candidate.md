## 1. Determination and scope

The previous v0.09.05 operating text fixed a real failure (story drift across comic collages) by enforcing **one sheet per user continuation**. That safeguard became inconvenient for a user who prefers a single full-run commission. Separately, the first page had been barred from becoming a cover, thereby missing an opportunity to orient a reader to the daily chronicle *without adding an extra page*. Finally, v0.09.05 explicitly deferred the ordinary eight-page default to upstream CC-01 policy alignment even while citing the old 16-page setting. The user now explicitly resolves the desired comic specialist behavior:

1. **First page:** approximately its upper 25%–33% must introduce the daily chronicle **while P01 itself carries real first-scene story events**, with creative use of first-scene objects and no standalone cover page.
2. **Budget:** default **8**, minimum **4**, maximum **20**; explicit eligible N overrides default and N includes P01.
3. **Cadence:** **no default between-sheet pause**. The entire authorized sequence should proceed automatically within the same active interaction; pause only if expressly instructed or a genuine blocker occurs.

These changes are **jointly** implemented in CC-03.01, this review/trace document, and CC-03.03 QA/manifest. They preserve the v0.09.06 strict 9:16 geometry rule and its stop-on-failed-measurement requirement. A pause for human permission is removed by default; an **internal measured-QA failure stop remains binding**. There is no permission to work asynchronously, fake completed assets, skip approvals for public portrayal, or fabricate capabilities of image providers.

## 5. Compatibility with CC-01/CC-02 and historical example

**Declared upstream collision:** CC-01.01 v0.09.01 §42 historically states ordinary N16, whereas this specialist v0.09.07 candidate selects N8 based on the owner's latest request. This revision does **not** modify the separate CC-01 file. The appropriate next governance action is a **separate synchronized CC-01.01 amendment** (and related QA/trace if needed) confirming the new default. Meanwhile an explicitly selected comic request using this new specialist edition applies N8; an explicit source/job N16 continues at N16.

**Chronicle Day 04 example:** the historical `S00CH05E03DAY04` N16 page map in v0.09.05 is a case study, not template story content for subsequent days. The new P01 rule would require a *same-ID* page revision incorporating the real Day 04 title/date/first beat, never an uncommissioned `P00` or `P17`. No existing Day 04 image is retroactively declared geometry-correct, and its older stepped commission retains original user-selected scope.

**Chronicle Day 05 2:3 incident:** the four 1024×1536 four-page collages from 20 Nov 2026 yielded sixteen extracted 512×768 (2:3) crops; this remains a geometry failure. A new mode that proceeds automatically must **stop after S01** if that same issue recurs, rather than compounding a defect across all pages. The user may separately request remediation of old artwork; this document review alone regenerates nothing.
