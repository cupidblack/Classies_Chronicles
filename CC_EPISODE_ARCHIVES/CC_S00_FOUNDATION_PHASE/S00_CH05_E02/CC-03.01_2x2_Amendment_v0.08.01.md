# CC-03.01 — Master Comic Generation Prompt
## Quality-first 2×2 collage amendment · proposed v0.08.01

**Scope:** This is a complete, directly usable **override/amendment** to the 4×4-sheet assumptions in `CC-03.01-Master_Comic_Generation_Prompt_v0.08.00.md`; it does **not** replace unrelated canon, rights, challenge, QA, release or story-fidelity rules. The original file has not been modified on GitHub and this amendment is not owner-ratified. When adopted for the specific `S00_CH05_E02` commission, apply the following text to the existing specialist, replacing contrary 4×4 *preferences* (including introductory table, §§21–23, §25 stage 4, §32–33 references and §35). All 22 named comic C-gates remain in force.

## 1. Replacement executive collage and page-count rule

For an explicitly commissioned sixteen-page Classies Chronicles adaptation, create **sixteen complete, individually meaningful, source-faithful portrait comic pages**, each 9:16 width:height. Produce/deliver **four separate graphic collage sheets**, each consisting of **exactly four complete pages arranged in two columns by two rows (2×2)**. The global page order is row-major within each sheet and sequential across sheets: Sheet 1 contains pages 01–04; Sheet 2, 05–08; Sheet 3, 09–12; Sheet 4, 13–16. **Do not generate a 4×4 sixteen-page collage** for this commission. If the user explicitly commissions a different total number of pages, honor that number and split into 2×2 groups where feasible, clearly marking any final partial batch as nonstandard rather than inventing padding pages.

A 2×2 collage is the default *batching and delivery* unit, not an excuse to create four panels masquerading as four pages. Every cell must constitute a story-complete 9:16 page, including its own legible panel sequence, source-supported action, emotions, dialogue and transitions.

## 2. Replacement geometry, export and slicing rule (§21)

For every independent comic page, set width W and height H with H=16W/9. Prefer true **1080×1920 native pixels per page** (or larger native 9:16 as supported). A **2×2 sheet** without gutters must be **(2W)×(2H)**, therefore **2160×3840** for four 1080×1920 pages; sheet aspect is 9:16. This is a *target*, not a claim that every image-generation provider can produce that native canvas. An outer **1080×1920** collage contains only four **540×960** cells and must not be labeled as four full-resolution 1080×1920 pages. Enlarging low-resolution cells afterward does not recreate missing lettering or character details.

Each sheet has four ordered cells:

| Sheet cell | Row/column zero-indexed | Page offset | Pixel crop if W=1080, H=1920, no gutters |
|---|---|---:|---|
| Top-left | r=0,c=0 | +1 | x=[0,1080), y=[0,1920) |
| Top-right | r=0,c=1 | +2 | x=[1080,2160), y=[0,1920) |
| Bottom-left | r=1,c=0 | +3 | x=[0,1080), y=[1920,3840) |
| Bottom-right | r=1,c=1 | +4 | x=[1080,2160), y=[1920,3840) |

For sheet index s=0,1,2,3, the global page number is **p=4s+2r+c+1**. With gutters/margins, use measured boundaries, `(2W+g_x+2m_x)×(2H+g_y+2m_y)`, and never assume percentage cropping is exact. Pages must remain 9:16, with safe margins inside each cell; no speech, panel or body part crosses a cut line.

## 3. Replacement renderer-aware batch procedure (§22)

Before generating any sheet, perform source and visual-rights preflight, build the complete sixteen-page beat map, and lock all approved/provisional character reference sheets, episode props, three-clock boundaries, dialogue and the terminal public question. Then perform **four separate 2×2 renders**, updating a per-sheet continuity handover after each actually generated sheet. If the image model cannot deliver native, readable 2160×3840 sheets, **render four individual full-resolution 9:16 pages and assemble a 2×2 sheet locally** using genuine page images; state the actual production method. Never quietly substitute a 4×4 low-resolution preview or claim individual page files exist before they are actually exported.

For every sheet, preserve the same approved character appearance, scene geography, attire evolution, injury state, emotional stakes, instrument props and typography rules. Give each page enough visual area for readable dialogue; prefer verified typesetting afterward where generation garbles speech. Generate in order, maintain source scene/beat references and inspect each page against predecessor/successor continuity. Re-render only defective sheets/pages whose dependencies require it.

## 4. Replacement crop, QA and final challenge requirements (§23)

After a real sheet exists, record its actual pixel dimensions, aspect ratio, file path, checksum, four page IDs, source manuscript revision, source scenes and image-generation settings only where obtained. Verify exactly four cells, correct row-major order and page bounds. Crop each 9:16 page using measured W/H and margins; verify all four exported pages with full-size mobile previews for lettering, faces, panel order, backgrounds and cut edges. Use actual image asset inventory and run the original C01–C22 gate sequence; report failures accurately. Image quality and rights cannot be certified by math alone.

The **episode's exact authorized public challenge must appear exactly once, inside the final story page (page 16, bottom-right cell of Sheet 4)**, at the lowest visible position on that page. There must be no logo, page number, caption, metadata clue or other element visibly beneath it, and no answer hint in the other pages. The rendered challenge should be typeset legibly without omitting its choices or instructions; if one page cannot legibly hold it, revise the storytelling layout or seek authorized textual reduction rather than silently dropping challenge material.

## 5. Replacement production order and blocking rule (§25, §32, §35)

1. Confirm `COMIC_GENERATE` is independently commissioned, source A revision/approval or authorized provisional use, B continuity permissions and effective adopted amendment.
2. Inspect existing released comic art and each featured character's **actual** approved reference assets in the character folder; if a visual collage URL is absent, check existing graphics first. Create a separate consistent original character reference sheet only when visual generation is commissioned and portrayal rights are cleared. Do not copy real-person likenesses without rights.
3. Plan sixteen non-filler 9:16 pages with exact speech, scene source, camera/action, character-state and event-boundary mapping; map pages to Sheets 1–4.
4. Generate **Sheet 1 2×2** (or the four independent full-size pages from which to assemble it). Validate before using its appearance anchors in Sheet 2. Repeat for Sheets 2, 3 and 4.
5. Check native image dimensions, legibility and continuity in real assets, then slice/assemble where requested; distinguish actual 4-sheet output, sixteen crop files, or partial delivery.
6. Inspect the final challenge in page 16, run applicable 22 C-gates, and prepare separate private provenance, limitations and handover. Do not generate comics during an episode-text request or begin media prompts without a distinct later commission.

**Blocking rule:** If the renderer cannot produce a readable four-page 2×2 sheet, switch to full-resolution individual pages and construct the 2×2 sheet from verified assets. If even page-specific quality or permissions are unavailable, document a partial or planned deliverable; **do not claim success for nonexistent images**. Any source A revision, rights change or visual-canon correction makes its affected derivatives stale.

## 6. QA acceptance criteria for the new batch policy

- Four independent 2×2 collage assets when a sixteen-page adaptation is requested; exactly sixteen meaningfully distinct portrait pages represented, not four giant panels or repeated scene copies.
- Every exported page actually 9:16 with physically measured dimensions; four pages per sheet in the correct order.
- Native pixel/lettering quality inspected; no claim that an upscaled 540×960 crop is a native 1080×1920 page.
- Character canon/visual consistency and actual image rights checked, especially after changing sheets.
- Original comic C01–C22 applied, with only real tests marked PASS.
- One unaltered public terminal challenge on page 16 with nothing beneath; no restricted answer or revealing hints.
- Correct differentiation among `PLANNED`, `STORYBOARDED`, `RENDERED_DRAFT`, `SLICED_VERIFIED`, `QA_PASSED`, `APPROVED` and `PUBLISHED_VERIFIED`.

**Adoption and persistence:** A project owner can select this amendment as an authorized scoped override for `S00_CH05_E02` or promote it via a reviewable successor of CC-03.01. Nothing in this amendment writes to GitHub, accepts draft character canons, invokes image generation, or publishes a comic.
